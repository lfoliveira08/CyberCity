| Decision | Rationale |

### Lessons learned
| Issue | Resolution | Applies to |
|---|---|---|
| The Phase B firmware rule "every coil write is a fresh hub command" is wrong for a polling master: OpenPLC rewrites the whole coil block every poll (`modbus_write_bits` each cycle, then sleep), so it overrides any local state within one poll. The warning was in the Phase B Build_Log lessons since Oct 6 | Firmware now counts a write only when the value differs from the last hub value; verified on BSH lights and fan | FH-PowerBox (same change made, not tested); any node with a local override and a level coil. The Door and Elevator coils are momentary and not affected |
| A held SCADA bit means different things per node: Door = keeps the gate open and blocks the reader; Elevator = pulse needed; PowerBox (after the change) = harmless, the button still works | Choose the ladder per node from what the firmware does with a repeated write | all nodes |
