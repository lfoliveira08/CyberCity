## What it is

A web-based SCADA/HMI with a browser editor. Per the page: Modbus RTU/TCP, OPC-UA, BACnet/IP, MQTT, Siemens S7, EtherNet/IP and other protocols; a built-in historian (SQLite or InfluxDB). About 5,100 stars and 2,902 commits on `master`. Docker: `docker pull frangoteam/fuxa:latest`, web UI on port 1881.
