## Lessons learned
| Issue | Resolution | Applies to |
|---|---|---|
| The installer rejected `--mode text` (this is a makeself package). | Installer options go after `--`: `-- unattended=text`. | Any Ignition 8.3 Linux install |
| Activation asked for an activation token as well as the key. | The Capstone license file carries the token; paste it on the activation screen. Never put the token in the repo or the Claude project. | The Capstone license |
| License shows a rolling lease: "expires in about 72 h, will automatically renew". | Inferred from the screen, not from Inductive docs: keep VM 101 able to reach the internet, and do not isolate it for more than about two days. | VM 101, attack-scenario network isolation |
