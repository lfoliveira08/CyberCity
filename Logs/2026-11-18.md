## Lessons learned
| Issue | Resolution | Applies to |
|---|---|---|
| S6's first run failed to capture — `cd ~/cybercity/s06_blackout && sudo tcpdump ...` errored `No such file or directory`, so the `&&` chain never started tcpdump, and the attack ran uncaptured from `~`. | The Nov 9 `mkdir -p ~/cybercity/{...}` command was written before Scenario 6 existed (it was still the dropped "ATS" slot at the time), so `s06_blackout` was never created. Created it now (`mkdir -p ~/cybercity/s06_blackout`); re-ran captured. **Check that a scenario's folder actually exists before chaining `cd && tcpdump` for it** — a failed `cd` silently skips the capture with no attack blocked. | any new scenario's capture folder |
